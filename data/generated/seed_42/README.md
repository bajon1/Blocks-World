# Zestawy eksperymentalne

- `base.txt`: po 5 problemów dla każdego `N` od 3 do 15, ziarno 42.
- `n8_extended.txt`: 10 problemów dla `N=8`, ziarno 42, przeznaczonych do
  porównania DFS i BFS w wariancie rozszerzonym.

Każdy wiersz zawiera jeden przypadek. Stan początkowy i docelowy są
rozdzielone przecinkiem, na przykład `2 0 0, 3 0 0`.
